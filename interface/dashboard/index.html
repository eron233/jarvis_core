JARVIS
Sistema operacional. Peça um relatório de status, uma análise de segurança do código, uma pesquisa na web, uma análise Graphify, ou converse normalmente.

⛨ Análise Estática de Código

Varre arquivos Python em busca de padrões inseguros (execução dinâmica, shell, desserialização, segredos embutidos, hash fraco). Análise defensiva.

▣ Micro-Sandbox Isolado

Executa código Python em subprocesso isolado, com portão de segurança AST (bloqueia imports perigosos, eval/exec/open) e limites reais de CPU/memória.

⌕ Pesquisa Web Ativa

Busca real na web e extrai as principais fontes. Requer que o ambiente tenha acesso de saída à internet.

◈ Análise Topológica Graphify

Estrutura uma descrição em grafo: extrai nós, arestas, calcula densidade, grau, hub e detecta ciclos reais.
